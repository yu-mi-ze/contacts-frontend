# 通讯录管理系统前端

## 项目简介
这是一个通讯录管理系统的前端实现，提供友好的用户界面，支持联系人的添加、查看、编辑和删除功能。

## 技术栈
- HTML5
- CSS3
- JavaScript (原生)

## 项目结构
```
contacts_frontend/
├── src/                      # 源代码目录
├── contacts.html             # 主页面文件
├── README.md                 # 项目说明
└── codestyle.md              # 代码规范
```

## 功能特点

### 1. 添加联系人
- 输入姓名和手机号码
- 点击"添加联系人"按钮保存
- 数据验证确保输入合法性

### 2. 查看联系人
- 自动显示所有已添加的联系人
- 每个联系人显示姓名和手机号码

### 3. 编辑联系人
- 点击联系人旁的"编辑"按钮
- 在弹出的模态框中修改信息
- 点击"保存修改"更新数据

### 4. 删除联系人
- 点击联系人旁的"删除"按钮
- 确认后删除联系人

## 离线功能
- 在没有后端服务的情况下，系统会自动使用浏览器本地存储（localStorage）保存数据
- 页面刷新后数据不会丢失
- 当后端服务可用时，会自动使用后端API

## 界面设计
- 采用现代化的卡片式布局
- 响应式设计，适配不同屏幕尺寸
- 友好的交互体验，包括模态框、确认提示等
- 清晰的视觉层次和色彩搭配

## 使用方法

### 直接运行
1. 用浏览器打开 `contacts.html` 文件即可使用
2. 系统会自动使用本地存储功能

### 与后端配合使用
1. 确保后端服务已启动（默认端口3000）
2. 用浏览器打开 `contacts.html` 文件
3. 系统会自动尝试连接后端API

## 浏览器兼容性
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 注意事项
- 如果后端服务未启动或无法连接，系统会自动切换到本地存储模式
- 本地存储数据仅保存在当前浏览器中，切换浏览器或清除缓存会导致数据丢失
- 建议在有后端服务的环境中使用，以获得更好的数据持久化支持
